# AI EdgeLabs

> AI-native runtime security for workloads, agents, and edge infrastructure. Detects, blocks and responds to threats in real time across every workload, container, model and agent — with built-in NIS2/CRA compliance, zero data egress.

## Platform

- [Workloads & Application Security](https://edgelabs.ai/platform/workloads-application-security): Runtime protection for AI workloads and applications
- [Kubernetes & Container Security](https://edgelabs.ai/platform/kubernetes): eBPF-based security from admission to runtime
- [Network Protection](https://edgelabs.ai/platform/network-protection): Real-time network threat detection and IP blocking
- [AI / LLM Security](https://edgelabs.ai/platform/ai-llm-security): Runtime defense for LLM workloads and AI agents
- [Vulnerability Management](https://edgelabs.ai/platform/vulnerability-management): CVE detection with exploit probability scoring
- [Compliance Center](https://edgelabs.ai/platform/compliance-center): NIS2 and CRA compliance tracking in a single dashboard
